# 💊 MediQuick Pharmacy Web App

A modern, responsive **online pharmacy web application** built using HTML, CSS, and JavaScript.
It allows users to browse medicines, add products to cart, and simulate order placement — all in a clean UI.
Created to learn HTML and CSS
---

## 🚀 Features

### 🛍️ User Side

* Browse medicines by category
* Search products instantly
* Add items to cart
* View cart with total price
* Checkout simulation
* Order storage using localStorage

### 🎯 Smart UI

* Responsive layout (mobile + desktop)
* Clean card-based design
* Category filtering
* Dynamic product rendering
* Real-time cart updates

### 🛒 Cart System

* Add multiple quantities
* Live total calculation
* Slide-in cart panel
* Order persistence

### 🔐 Admin Panel

* Simple login system (password: `admin123`)
* View placed orders
* Add new products dynamically
* Category-based product management

---

## 🧠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Storage:** Browser LocalStorage
* **Styling:** Custom CSS (with modern UI design)
